vue-pdf-document turns Vue components into PDF files. You write `<Document>`, `<Page>`, `<View>` and `<Text>` in a template, with props, `v-for`, `v-if` and computed values, and get a real PDF with text you can select, in the browser or in Node.

## How it works

[react-pdf](https://react-pdf.org) is split into packages, and only `@react-pdf/renderer` knows about React. The rest, the layout engine (`@react-pdf/layout`, built on Yoga flexbox), text shaping, pagination and the PDF writer, take a plain tree of nodes. This library builds that tree with Vue's `createRenderer` instead of React's reconciler, then hands it to the same engine:

1. Vue mounts your component with a custom renderer whose nodes have the shape the layout engine reads.
2. Reactive changes patch that tree like they would patch the DOM.
3. On render, a copy of the tree goes through `@react-pdf/layout` and `@react-pdf/render`, which draw it with pdfkit.

So layout, styles, fonts and pagination behave exactly as in react-pdf, and its docs on [styling](https://react-pdf.org/styling) and [advanced layout](https://react-pdf.org/advanced) apply as written.
