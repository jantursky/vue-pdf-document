---
title: Fonts
description: Register custom fonts, emoji and hyphenation.
---

The standard PDF fonts (`Helvetica`, `Times-Roman`, `Courier` and their bold and oblique variants) work without setup. Anything else is registered once, before the first render, with `Font`, which is react-pdf's font store with the same API:

```ts
import { Font } from 'vue-pdf-document'

Font.register({
  family: 'Inter',
  fonts: [
    { src: '/fonts/Inter-Regular.ttf' },
    { src: '/fonts/Inter-Bold.ttf', fontWeight: 700 },
    { src: '/fonts/Inter-Italic.ttf', fontStyle: 'italic' },
  ],
})
```

Then use the family in a style: `{ fontFamily: 'Inter', fontWeight: 700 }`. TTF and WOFF work; WOFF2 doesn't.

Emoji come from an image source, and hyphenation can be replaced:

```ts
Font.registerEmojiSource({ format: 'png', url: 'https://cdnjs.cloudflare.com/ajax/libs/twemoji/14.0.2/72x72/' })
Font.registerHyphenationCallback((word) => [word]) // never hyphenate
```

See [react-pdf's font docs](https://react-pdf.org/fonts) for every option.
